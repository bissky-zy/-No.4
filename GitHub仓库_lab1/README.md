## 1 项目背景与范围

校园内的闲置书籍信息分散在聊天群里：书是否仍可售、是否已被他人预留、取消后能否再次购买，往往需要反复询问。本项目设计一个校园二手书交易平台，让用户发布和查找书籍，并通过下单、取消表达预留意向。这是用于需求分析的模拟项目，不要求开发可运行系统。

纳入范围（4 项核心业务、5 个用例）：

| 核心业务 | 对应用例 |
| --- | --- |
| 发布书籍 | UC-01 发布书籍 |
| 检索与查看 | UC-02 检索书籍、UC-03 查看书籍详情 |
| 下单（预留） | UC-04 下单预留 |
| 取消订单 | UC-05 取消订单 |

明确排除：真实支付与退款、物流与取货、交易完成确认、评价与推荐、注册与找回密码（实验统一使用预置测试账号）。

基本约定：下单仅表示预留，不表示付款；同一本书同一时刻最多一个有效订单；仅订单买家本人可取消，取消后书籍恢复可售、历史订单保留；不接入支付、物流、交易完成、评价与推荐。
