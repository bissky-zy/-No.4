# 表设计与数据字典（v1.0 · 2026-11-13）

依据概念 ER 图（01_概念ER图.png）转换。转换规则：每个实体转一张表，实体标识即主键；1:n 联系在 n 端引入外键。
状态取值对齐实验一：listing_status（A 可售 / R 已预留 / S 已售出，暂定）、order_status（N 有效 / C 已取消，暂定）。

## 表1 用户表（user）

用途：保存预置测试账号对应的用户信息。同一账号可按情境充当买家或卖家（B-03），不设角色字段。

| 字段名 | 含义 | 类型与长度 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| user_id | 用户标识（主键） | INT | 否 | 自动递增 | PK |
| account | 登录账号 | VARCHAR(30) | 否 | 无 | UNIQUE |
| password | 登录密码 | VARCHAR(64) | 否 | 无 | 不明文存储（NFR） |
| nickname | 昵称 | VARCHAR(30) | 否 | 无 | |
| contact | 联系方式（邮箱/手机） | VARCHAR(50) | 是 | NULL | 取值形式暂定 |

## 表2 书籍发布表（book_listing）

用途：保存书籍发布记录，一条记录代表一本实物书（BR-01），不设库存数量。

| 字段名 | 含义 | 类型与长度 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| listing_id | 发布标识（主键） | INT | 否 | 自动递增 | PK |
| seller_id | 卖家用户标识 | INT | 否 | 无 | FK→user.user_id |
| title | 书名 | VARCHAR(100) | 否 | 无 | |
| author | 作者 | VARCHAR(50) | 否 | 无 | |
| isbn | ISBN 号 | VARCHAR(20) | 是 | NULL | |
| condition | 成色 | VARCHAR(10) | 否 | 无 | 四档：全新/九成新/七成新/有明显笔记（Q-02 暂定） |
| price | 价格 | DECIMAL(8,2) | 否 | 无 | CHECK 1≤price≤500（Q-03 暂定） |
| description | 描述 | TEXT | 是 | NULL | |
| listing_status | 书籍状态：A 可售 / R 已预留 / S 已售出 | CHAR(1) | 否 | A | 取值暂定 |
| publish_time | 发布时间 | DATETIME | 否 | 无 | |

## 表3 订单表（order_record）

用途：保存预留订单；取消只改状态、不改历史（BR-05、BR-08）。

| 字段名 | 含义 | 类型与长度 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| order_id | 订单标识（主键） | INT | 否 | 自动递增 | PK |
| buyer_id | 买家用户标识 | INT | 否 | 无 | FK→user.user_id |
| listing_id | 关联发布标识 | INT | 否 | 无 | FK→book_listing.listing_id |
| order_status | 订单状态：N 有效 / C 已取消 | CHAR(1) | 否 | N | 取值暂定 |
| create_time | 下单时间 | DATETIME | 否 | 无 | |
| cancel_time | 取消时间 | DATETIME | 是 | NULL | 取消时写入 |

## 关键约束的落地说明

- 「同一书籍同一时刻最多 1 个有效订单」（BR-03）无法仅靠外键表达，由应用层在事务内保证：下单时检查该发布是否已存在 order_status=N 的订单，不存在才允许插入。
- 身份校验（仅买家本人可取消，BR-04）与跨表状态更新（取消时同步恢复书籍可售）同属应用层或事务责任。
- 旧订单的取消请求再次到达不得影响该书籍当前的新订单（BR-07）：取消按订单标识定位、只对「有效」订单生效。
