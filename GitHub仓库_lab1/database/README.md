## 设计要点（与实验一需求的对应）

- 三个实体（用户、书籍发布、订单）来自实验一用例 UC-01/UC-04/UC-05 需要持久保存的数据（FR-01、FR-05、FR-07）。
- 「同一本书同一时刻最多一个有效订单」（BR-03）由订单状态字段 + 应用层事务保证，外键只保证引用存在。
- 「取消不改历史」（BR-05）由订单状态与取消时间字段支撑，取消为状态变更而非删除。
- 价格合法范围 1—500 元（Q-03，暂定）、成色四档：全新/九成新/七成新/有明显笔记（Q-02，暂定）。
